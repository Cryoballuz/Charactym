## 2. 数据模型

一张字 = 一条记录 + 一张 PNG：

```
表名: glyphs（人造文字表）
  id         主键：自动分配"最小可用编号"（从 1 起找第一个空缺，删除后的编号会被新字复用，保证编号连续）；同时用作 PNG 文件名
  hanzi      映射字：0 或 1 个 Unicode 码点字符（可为空，允许非汉字/单码点 emoji），建立索引（用于搜索）
  note       备注，可空字符串
  pngPath    图片文件路径（应用私有目录内，如 files/glyphs/12.png）
  createdAt  录入时间戳（毫秒）
  updatedAt  最后修改时间戳（毫秒）
```

- 同一 hanzi 允许多条记录（变体），数据库不设唯一约束。
- 编辑时：修改字段 + 覆盖原 PNG（保留原 id 与 createdAt）；重画时覆盖 PNG。

## 3. 画布（256×256 黑白）实现要点

- **内存表示**：`ByteArray(256*256)`，每个字节 0（白）/ 255（黑），共 64KB，非常小。
- **落笔算法**：手指滑动时，用直线插值（Bresenham 线段算法）填充两次触点之间的格子，保证笔画连续。
- **笔刷粗细**：三档共用选择器——画笔 小/中/大 = 4/8/12 格；橡皮 小/中/大 = 10/20/30 格（以触点为中心的方形笔头）。
- **撤销**：保存最近 50 步的画布快照（每步 64KB，共约 3.2MB，可接受）。撤销=恢复上一快照；清空=压入快照后全部置白。
- **显示**：256×256 画布按屏幕宽度缩放显示，保持正方形；通过变换矩阵支持双指缩放与拖动；辅助线（横纵各 3 根分 4×4=16 格 + 两条对角线）按需叠加绘制（可开关）。
- **触点→格子换算**：由当前缩放/偏移矩阵逆变换得到格子坐标。
- **保存为 PNG**：`Bitmap.createBitmap(256,256)` 逐格写入黑白像素后压缩为 PNG（白底黑字）。

## 4. 搜索实现

- 数据量在个人文字库级别（几十~几千条），无需全文检索引擎。
- 直接使用 SQL 模糊查询：`WHERE hanzi LIKE '%关键词%' OR note LIKE '%关键词%'`。
- 结果按录入时间新→旧排列。

## 5. 导出 PNG 与备份（已实现，2026-08-19）

- **导出位置**：系统「下载/Charactym」文件夹（Android 10+ 通过 MediaStore.Downloads，无需任何权限；旧系统直接写公共下载目录）。
- **导出 PNG**：支持单张（详情页按钮）与全部（管理页按钮）；文件名 `<映射字>_<id>.png`（无映射字时用 `<id>.png`）。
- **整体备份**：zip 文件 `Charactym备份-yyyyMMdd-HHmm.zip`，内含：
  - `manifest.json`：格式版本号（当前 1）、应用版本、条数、时间；
  - `glyphs.json`：全部文字数据（id/映射字/备注/时间戳，kotlinx-serialization-json）；
  - `images/<id>.png`：全部字图。
- **恢复备份**：SAF 文件选择器选 zip → 校验版本 → **覆盖式导入**（清空现有数据后按原 id 恢复，恢复前有确认弹窗）。
- 备份文件含版本号字段，便于将来升级兼容。

## 6. 界面结构（页面清单）

| 页面 | 说明 |
| --- | --- |
| 录入页（主界面） | 画布 + 工具按钮 + 映射字框（可选）+ 备注框 + 保存 |
| 浏览页 | 列表：缩略图 + 映射字（可空）+ 备注摘要；右上角「⚙️ 管理」入口 |
| 详情页 | 大图 + 映射字（可空）+ 完整备注 + 编辑/导出PNG/删除按钮 |
| 编辑页 | 复用录入页，预填原数据，保存即更新 |
| 搜索页 | 一个搜索框同时搜映射字与备注 + 结果列表 |
| 映射页 | 输入字符串 → 按字符顺序排出对应字（淡红占位/淡蓝蒙版标多字）；横竖排 + 从左到右/从右到左切换 |
| 数据管理页 | 导出 PNG（单张/全部/多选）、批量导入图片、整体备份、恢复备份 |
| 底部导航 | 录入 / 搜索 / 浏览 / 映射 四个入口 |

## 6b. 扩展功能实现要点

- **映射页**：`observeByHanziIn(chars)` 一次查询输入串中出现的全部映射字（编号升序）；渲染为槽位列表（无字=淡红占位，多字=展开并盖淡蓝蒙版）；横排用 FlowRow 自动换行，竖排按列分块；「从左到右/从右到左」通过 `LocalLayoutDirection`（RTL）实现真正的书写方向，字符顺序不变。
- **多选导出**：浏览/搜索/映射三页本地维护选中 id 列表；长按（combinedClickable）进入多选，选中蓝色边框；浮动胶囊「导出 PNG」调用 `exportGlyphsToDownloads(ids)`；胶囊位置随输入法（`WindowInsets.ime` 减去底栏高度 + 12dp，`adjustNothing` 模式）。
- **批量导入**：SAF 多选图片 → 先读边界校验 256×256（不符跳过）→ 解码后按亮度阈值 50% 转黑白 → `repository.insert`（编号沿用最小空缺）；文件名（去扩展名）按所选模式作映射字（须单个字符）或备注；结果汇总报告（可滚动弹窗）。

## 7. 开发与验证方式

- 使用 adb 连接用户开发手机，每个阶段构建后安装到真机验证（截图确认）。
- 编译、安装、调试遵循 Android 官方 android-cli 工具链。
- 不做自动化 UI 测试（个人小工具，人工实机验证足够）；关键逻辑尽量保持简单直接，减少出错面。

## 8. 风险与对策

| 风险 | 对策 |
