# Charactym 设计规范

> 版本：v1.0　日期：2026-08-19
> 界面风格：简洁（简陋亦可接受）。配色主基调：淡蓝 - 白 - 灰。

---

## 1. 配色（统一色板）

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 主色 / 按钮 | `#7FA8D9` 淡蓝 | 保存、确认等主要按钮 |
| 主色（按下/选中） | `#5B8BC0` 深一点的淡蓝 | 按钮按下、工具选中 |
| 背景 | `#FFFFFF` 白 | 页面背景 |
| 浅灰背景 | `#F2F4F7` | 列表条目间隔、顶部栏底 |
| 卡片/输入框底 | `#FFFFFF` 白 + `#D9DEE6` 边框 | 输入框 |
| 分隔线 | `#E3E7EC` | 列表分隔 |
| 主文字 | `#333333` 深灰 | 标题、正文 |
| 次要文字 | `#8A94A3` 灰 | 提示、摘要 |
| 危险操作 | `#C96A6A` 淡红 | 仅用于"删除""清空"按钮 |
| 画布 | 白底 `#FFFFFF`，辅助线 `#C8D3E1`，笔画 `#000000` 纯黑 | 黑白画布 |

## 2. 文字排版

- 中文字体：跟随系统默认（不做特殊字体）。
- 字号：页面标题 20sp；正文 16sp；备注摘要/提示 12sp。
- 列表条目高度适中，缩略图约 40dp 见方。

## 3. 页面布局（自上而下）

### 3.1 底部导航（全局）
四个入口，从左到右：**录入 / 搜索 / 浏览 / 映射**。当前页高亮为淡蓝。
「管理」不在底栏，而是**浏览页右上角的「⚙️ 管理」小按钮**（进入后为带返回按钮的独立页面）。

### 3.2 录入页
```
┌─────────────────────────────┐
│  画布（正方形，辅助线可开关，可双指缩放） │
│                              │
├─────────────────────────────┤
│ [画笔][橡皮][撤销][清空]            │   ← 工具行（选中的工具底色变深蓝）
│ 笔刷: 小 / 中 / 大                   │   ← 三选一，选中高亮
│ 辅助线: [开关]      [视图复位]        │   ← 独立一行，互不遮挡
├─────────────────────────────┤
│ 映射字(可选): [____] ←可选，任意1个字符│
│ 备注(选填): [____________]   │
│ [        保 存        ]      │   ← 淡蓝主按钮，铺满宽度
└─────────────────────────────┘
```

### 3.3 浏览页
```
┌─────────────────────────────┐
│ 浏览        [⚙️ 管理]  ←右上角│
├─────────────────────────────┤
│ [图] 日  · 太阳……  · 08-19     │ ← 每条：缩略图+映射字+备注摘要+日期
│ [图] 月  · 月亮     · 08-19     │
│ …（按录入时间新→旧）            │
└─────────────────────────────┘
```

### 3.4 详情页
```
┌─────────────────────────────┐
│  ← 返回      （标题栏）        │
├─────────────────────────────┤
│        （大字图，居中）          │

│  备注：……（完整显示，可滚动）     │

```

### 3.5 搜索页
```
┌─────────────────────────────┐

├─────────────────────────────┤

### 3.5b 映射页（底栏最右「📜 映射」）
```
┌─────────────────────────────┐

## 4. 交互规则

| 场景 | 规则 |
| --- | --- |
| 映射字输入 | 可选；任意单个 Unicode 码点字符（可非汉字、单码点 emoji）；多输只取第 1 个；空白字符被过滤 |
| 映射字与备注都为空点保存 | 不保存，提示「映射字和备注至少填写一个」 |
| 无映射字的记录 | 浏览/搜索/详情中映射字位置留空，备注照常显示；导出文件名用 `<id>.png` |
| 保存时映射字已有对应文字 | 新建模式下弹确认框「该映射字符已有对应人造文字，字符「X」已对应 N 个人造字。您仍要保存这个新的写法吗？」——点「确认保存」才保存，点「取消」不保存；编辑已有记录或不填映射字时不提示 |
| 画布全白点保存 | 提示「画布还是空白的，确定保存吗？」，确认后可保存 |
| 撤销 | 无可撤销步骤时按钮置灰 |
| 清空画布 | 弹确认框「确定清空画布吗？」 |
| 删除记录 | 弹确认框「确定删除该文字吗？删除后不可恢复」 |
| 编辑 | 进入录入页并预填原数据，保存后覆盖更新 |
| 删除图片 | 删除记录的同时删除对应 PNG 文件 |
| 保存成功 | 弹轻提示「保存成功」，画布与输入框清空（便于连续录入） |
| 备份/导出完成 | 页面显示成功提示与文件位置 |
| 多选导出 | 浏览/搜索/映射三页：长按进入多选（选中显示蓝色边框），点选切换；底部浮动胶囊「取消/已选 N 张/导出 PNG」；导出完成后自动退出多选；按返回键退出；映射页中淡红占位不可选 |
| 批量导入 | 管理页选模式（文件名→映射字须单个字符 / 文件名→备注）→ 系统多选图片 → 非 256×256 跳过；亮度 50% 阈值转黑白；不弹重复确认；结果报告（可滚动） |

## 5. 其他约定

- 图标一律用简单文字或系统自带小图标，不做美工素材。
- 全部文案为简体中文。
- 缩略图由 256×256 原图按比例缩小显示，保持正方形。
