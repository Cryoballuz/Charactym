# Charactym 需求文档

> 版本：v1.0　确认日期：2026-08-19
> 本文档是开发的最权威依据。任何功能与本文档冲突时，以本文档为准；修改本文档需先经用户确认。

---

## 1. 项目概述

- **应用名称**：Charactym（后续可改）
- **用途**：记录用户自创的方块表意文字（人造文字）。每个人造文字是一张 256×256 像素的黑白图，映射到一个字符（映射字，可选、可为空），并附备注说明。
- **使用场景**：纯本地、单人使用；无需联网、无需登录账号。

## 2. 功能需求

### 2.1 录入界面（主界面）

- **画布**：256×256 像素，只有黑、白两种颜色（白底黑字），支持手指直接在触屏上书写绘制。
- **绘图工具**：画笔、橡皮、撤销、清空。
  - 画笔：触点经过的格子变黑。
  - 橡皮：触点经过的格子变白。
  - 撤销：回退上一步笔画，最多 50 步。
  - 清空：整张画布变白（清空前弹确认提示，防止误触）。
- **笔刷粗细**：细 / 中 / 粗 三档可选。
- **画布辅助**：辅助线（横纵各 3 根分成 4×4=16 格 + 两条对角线，可开关）+ 双指缩放画布，方便精细绘制。
- **映射字输入框**：
  - 可选，允许留空。
  - 填了就恰好 1 个字符：任意 Unicode 码点字符（可非汉字，如字母、假名、单码点 emoji），多输只取第 1 个。
  - 用于映射该人造文字。
- **备注输入框**：
  - 选填，允许留空。
  - 填写该字的含义等说明，例如「太阳」「行走」。
- **保存按钮**：将 256×256 黑白图 + 映射字 + 备注 一并保存。
  - 映射字和备注**至少填一个**，两个都空时禁止保存并提示。

### 2.2 浏览界面

- 以列表展示所有已录入的人造文字，每条显示：小缩略图 + 映射字（可为空，空则留白）+ 备注摘要。
- 默认按录入时间从新到旧排列。
- 点击任一条进入**详情页**：大字图 + 映射字 + 完整备注。
- 详情页提供**编辑**和**删除**按钮：
  - 编辑：可改映射字、改备注、重新绘制字图。
  - 删除：弹确认提示，确认后整条删除（连同图片文件）。

### 2.3 搜索界面

- **一个搜索框**，同时匹配映射字和备注（模糊匹配：输入片段即可）。
- 搜索映射字：直接搜出该字符对应的人造文字（可能多条，因为允许变体）。
- 搜索备注：搜出备注中包含输入内容的所有记录。
- 点击搜索结果进入详情页。

### 2.4 映射规则

- 同一个映射字符**允许对应多个人造字**（变体写法），重复保存同一映射字符时不覆盖、不报错（新建保存时弹确认框）。

### 2.5 数据管理（备份与导出）

- **导出 PNG**：将字图以 256×256 PNG 文件导出到手机（默认「下载」文件夹），可单张导出、也支持一键全部导出。
- **整体备份**：生成一个备份文件（含全部数据与图片），保存到手机存储。
- **恢复备份**：从备份文件一键恢复全部数据与图片。

## 3. 界面要求

- 界面简洁，简陋亦可接受。
- 配色以**淡蓝 - 白 - 灰**为主（具体色值见设计规范）。
- 界面语言：简体中文。

## 4. 非功能要求

- 完全离线可用，不申请联网权限。
- 数据存储在手机本地（应用私有目录 + 数据库）。
- 应用稳定、省电；256×256 图保存为白底黑字 PNG。
- 隐私：所有数据仅留在用户手机内，绝不上传。

## 6. 暂不包含的功能（明确排除）

- 联网、云同步、账号系统。
- 分享到社交平台。
- 把人造文字生成字体文件（TTF）——可作为以后的可选功能再讨论。
