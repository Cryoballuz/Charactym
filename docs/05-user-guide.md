# Charactym 使用手册

> 版本：v1.0　日期：2026-08-19
> 适用：Charactym Android 应用（记录您创造的方块表意文字）

---

## 1. 这是什么

Charactym 是您的人造文字记事本。每个人造文字是一张 **256×256 像素的黑白图**，
映射到一个映射字符（可选，可为空），并可附加备注（如含义）。所有数据只存在您的手机里，完全离线。

## 2. 界面总览

应用底部有四个页签（另有「管理」入口在浏览页右上角）：

| 入口 | 用途 |
| --- | --- |
| ✏️ 录入 | 画字 + 填映射字和备注 + 保存 |
| 🔍 搜索 | 一个搜索框同时搜映射字和备注 |
| 📚 浏览 | 查看所有已录入的文字，点击看大图，可编辑/删除；右上角「⚙️ 管理」 |
| 📜 映射 | 输入一串字符，按顺序排出对应的人造文字（可横排/竖排、从左到右/从右到左） |
| ⚙️ 管理 | （浏览页右上角）导出 PNG、批量导入、整体备份、恢复备份 |

## 3. 录入一个字

1. 在白色画布上用**手指书写**（单指 = 画笔；双指 = 放大/拖动，便于画细节）。
2. 工具行：「画笔」写字、「橡皮」擦除、「撤销」回退一步（最多 50 步）、「清空」重来（会先确认）。
3. 笔刷三档：**小/中/大**——画笔为 4/8/12 像素，橡皮为 10/20/30 像素（按钮上会显示当前数值）。
4. 「辅助线」开关：显示横纵各 3 根辅助线（把画布分成 16 格）和两条对角线，帮助定位；「视图复位」把画布恢复为铺满居中。
5. 「**映射字**」框可选，填了就恰好 1 个字符（汉字、字母、emoji 都行，多输只留第 1 个）；「备注」填含义等说明。
   **映射字和备注至少填一个**，两个都空不能保存。
6. 点「**保存**」：提示"保存成功"后画布自动清空，可继续录入下一个字。
7. 如果映射字之前已有对应文字，会弹确认框，点「确认保存」才保存（变体写法）。

> 小技巧：点按（不滑动）也能落一个点；画错了可以「撤销」，清空后也能「撤销」找回。
> 只有备注、没有映射字的字：浏览/搜索/详情里映射字位置留空，备注照常显示。

## 4. 浏览 / 详情 / 编辑 / 删除

- **浏览页**列出全部文字（缩略图 + 映射字 + 备注摘要 + 日期），新的排在最上。
- 点击任一条进入**详情**：大字图 + 映射字 + 完整备注。
- 「**编辑**」：预填原图原数据，可改映射字、改备注、重画字图，点「保存修改」即更新。
- 「**导出PNG**」：把这张字图以 PNG 存到手机「下载/Charactym」文件夹。
- 「**删除**」：确认后删除记录与字图（不可恢复，请谨慎）。

## 4b. 长按多选 + 批量导出 PNG（浏览 / 搜索 / 映射页）

1. **长按**任意一个字 → 进入多选模式，该字出现**蓝色边框**，底部浮出胶囊。
2. 点选/取消其他字；映射页里淡红占位方块不可选。
3. 胶囊显示「已选 N 张」，点「**导出 PNG**」→ 全部导出到「下载/Charactym」→ 自动退出多选。
4. 点「取消」或按返回键退出多选；键盘弹出时胶囊自动贴到键盘上方。

## 5. 搜索

- 一个搜索框**同时匹配映射字和备注**（模糊匹配）。
- 输入一个映射字 → 找到它对应的所有人造字（同一字可有多个变体）。
- 输入备注中的词（如「太阳」）→ 找到备注含该词的所有记录。
- 点「清空」重置；无结果显示"未找到相关文字"。

## 5b. 映射页（把输入串"翻译"成人造文字）

1. 输入一串字符（最多 200 个），下方按顺序排出每个字符对应的自造字。
2. 没有对应字的字符 → 显示**淡红色占位方块**；一个字符对应多个字 → 按编号从小到大依次排出，每个盖**淡蓝蒙版**。
3. 「横排/竖排」：横排自动换行上下滚动；竖排列满换列、**左右滑动**。
4. 「从左到右/从右到左」：横排控制行内方向；竖排控制列方向（左起=蒙古文式，右起=汉字书法式）。
5. 无映射字的记录不参与映射页。

## 6. 备份 / 批量导入 / 恢复（保护您的心血）

- 「**导出全部 PNG 图片**」：所有字图以 PNG 存到「下载/Charactym」。
- 「**批量导入图片（256×256）**」：先选方式——
  - 文件名 → 映射字：文件名须是单个字符（如 `日.png` → 映射字"日"）；
  - 文件名 → 备注：文件名（去扩展名）作为备注。
  然后系统多选图片；不是 256×256 的会被跳过并列出原因；非黑白图按 50% 亮度自动转黑白。
- 「**创建整体备份文件**」：生成一个 zip（含全部数据与字图），文件名形如 `Charactym备份-20260819-2130.zip`。
- 「**从备份文件恢复**」：选择备份 zip，确认后**覆盖**当前数据（恢复前有提示，请确认无误再继续）。

**换手机迁移**：旧手机「创建整体备份文件」→ 用文件管理器/数据线把 zip 拷到新手机 →
新手机装好 Charactym → 管理页「从备份文件恢复」选这个 zip。

## 7. 常见问题

- **界面会不会变黑？** 不会。应用固定浅色主题（淡蓝-白-灰），不跟随系统深色模式。
- **导出的文件在哪？** 手机「下载/Charactym」文件夹（用系统文件管理器查看）。
- **换手机后数据还在吗？** 见第 6 节，用备份文件恢复即可。
- **应用升级会丢数据吗？** 不会。应用采用安全的数据库升级策略，升级安装保留全部数据。

## 8. 提示

- 备注建议填含义或读音，方便日后搜索。
- 同一个映射字符可以保存多个不同写法（变体），搜索时会全部列出。
- 定期「创建整体备份文件」并拷贝到电脑/云盘，是对您文字库最稳妥的保护。
